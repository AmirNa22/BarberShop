# سامانه نوبت‌دهی آرایشگاه (Amir Style Studio)

سامانه سبک، مدرن و محلی برای نوبت‌دهی آنلاین آرایشگاه **Amir Style Studio** توسعه‌یافته با استک پایتون (Flask)، پایگاه‌داده محلی SQLite و رابط کاربری مدرن Vanilla با هویت بصری Dark & Warm Amber و فونت فارسی وزیرمتن.

---

## 🛠️ ساختار فایل‌های پروژه

```text
BarberShop/
├── backend/                  # کدهای سرور (Python + Flask)
│   ├── app.py                # مسیرهای API، اعتبارسنجی‌ها و قوانین R1 تا R4
│   ├── database.py           # ساخت جداول پایگاه‌داده و مقداردهی اولیه خدمات
│   ├── barbershop.db         # فایل پایگاه‌داده محلی SQLite
│   └── requirements.txt      # وابستگی‌های پایتون (Flask, Flask-CORS)
├── frontend/                 # رابط کاربری (HTML, CSS, JS خام)
│   ├── index.html            # صفحه اصلی و ویترین خدمات آرایشگاه
│   ├── booking.html          # صفحه فرم رزرو نوبت و کارت تأییدیه نهایی
│   ├── appointments.html     # پنل مدیریت نوبت‌های روزانه ویژه صاحب‌کار
│   ├── style.css             # استایل‌های سراسری، فونت وزیرمتن و طراحی واکنش‌گرا
│   ├── app.js                # دریافت خدمات و بررسی سلامت سرور در صفحه اصلی
│   ├── booking.js            # منطق انتخاب اسلات آزاد، اعتبارسنجی و ثبت نوبت
│   └── appointments.js       # دریافت نوبت‌های روز، فیلتر تقویم و لغو نوبت
├── docs/
│   └── PRD.md                # سند نیازمندی‌های محصول (PRD)
├── AGENTS.md                 # قوانین و دستورالعمل‌های کاری پروژه
└── README.md                 # راهنمای جامع راه‌اندازی و اجرای پروژه
```

## 📋 پیش‌نیازها

- **پایتون:** نسخه 3.8 یا بالاتر (پیشنهادی: Python 3.10+)
- **مرورگر وب مدرن:** مانند Chrome، Firefox یا Edge

## 🚀 راهنمای سریع راه‌اندازی و اجرا (از صفر)

### گام اول: اجرای سرور بک‌اند (Backend)

1. ترمینال (یا PowerShell) را باز کرده و به پوشه `backend` بروید:
   ```powershell
   cd backend
   ```

2. (پیشنهادی) یک محیط مجازی پایتون ایجاد و فعال کنید:
   - در ویندوز (PowerShell):
     ```powershell
     python -m venv venv
     .\venv\Scripts\activate
     ```
   - در لینوکس / مک:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```

3. وابستگی‌های پروژه را نصب کنید:
   ```powershell
   pip install -r requirements.txt
   ```

4. سرور را اجرا نمایید:
   ```powershell
   python app.py
   ```
   > سرور روی آدرس `http://127.0.0.1:5000` اجرا خواهد شد و فایل دیتابیس `barbershop.db` به صورت خودکار ایجاد و مقداردهی می‌شود.

---

### گام دوم: اجرای رابط کاربری (Frontend)

برای مشاهده رابط کاربری می‌توانید از یکی از دو روش زیر استفاده نمایید:

#### روش اول (ساده‌ترین راه):
به پوشه `frontend` رفته و مستقیماً روی فایل `index.html` دابل‌کلیک کنید تا در مرورگر پیش‌فرض شما باز شود.

#### روش دوم (با سرور محلی پایتون - پیشنهادی):
یک ترمینال جدید باز کرده و دستور زیر را اجرا نمایید:
```powershell
cd frontend
python -m http.server 3000
```
سپس در مرورگر خود آدرس‌های زیر را باز کنید:
- **صفحه اصلی آرایشگاه:** [http://127.0.0.1:3000/index.html](http://127.0.0.1:3000/index.html)
- **فرم رزرو نوبت:** [http://127.0.0.1:3000/booking.html](http://127.0.0.1:3000/booking.html)
- **پنل مدیریت نوبت‌های صاحب‌کار:** [http://127.0.0.1:3000/appointments.html](http://127.0.0.1:3000/appointments.html)

## 📡 مسیرهای اصلی سرور (API Endpoints)

| متد | مسیر (Route) | توضیحات |
| :--- | :--- | :--- |
| `GET` | `/api/test` | بررسی سلامت و برقراری ارتباط سرور |
| `GET` | `/api/services` | دریافت فهرست کامل خدمات به همراه قیمت و زمان |
| `GET` | `/api/available-slots?date=YYYY-MM-DD` | استعلام وضعیت اسلات‌های ۳۰ دقیقه‌ای (آزاد یا پر) |
| `POST` | `/api/appointments` | ثبت نوبت جدید با اعتبارسنجی قوانین R1 تا R3 و موبایل ایران |
| `GET` | `/api/appointments?date=YYYY-MM-DD` | دریافت لیست نوبت‌های یک روز مشخص به ترتیب ساعت |
| `POST` | `/api/appointments/<id>/cancel` | لغو نوبت و آزادسازی بازه زمانی طبق قانون R4 |

## ⚖️ قوانین کسب‌وکار پیاده‌سازی‌شده

- **قانون R1:** ساعات کاری روزانه از ۱۰:۰۰ تا ۲۰:۰۰ و صرفاً در اسلات‌های ۳۰ دقیقه‌ای مشخص است.
- **قانون R2:** در هر اسلات تنها یک نوبت امکان رزرو دارد؛ رزرو مجدد در زمان پر شده در بک‌اند رد می‌شود.
- **قانون R3:** ممانعت قطعی از رزرو نوبت برای تاریخ یا ساعات گذشته در سمت سرور.
- **قانون R4:** لغو نوبت به هیچ‌وجه رکورد را حذف نمی‌کند؛ بلکه وضعیت آن را به `cancelled` تغییر داده و بازه زمانی را برای رزرو جدید بلافاصله آزاد می‌سازد.
- **اعتبارسنجی فیلدها:** محدودیت طول نام (۲ تا ۵۰ کاراکتر) و شماره تماس ۱۱ رقمی معتبر ایران با پیش‌شماره ۰۹ (همراه با پشتیبانی از ارقام فارسی).
