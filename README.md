
## 🚀 راهنمای گام‌به‌گام اجرا

### ۱. اجرای سرور بک‌اند (Backend)

1. ترمینال را در ریشه پروژه باز کرده و وارد پوشه `backend` شوید:
   ```powershell
   cd backend
   ```

2. (اختیاری اما پیشنهادی) یک محیط مجازی پایتون (Virtual Environment) بسازید و فعال کنید:
   ```powershell
   python -m venv venv
   .\venv\Scripts\activate
   ```

3. وابستگی‌های پایتون را نصب کنید:
   ```powershell
   pip install -r requirements.txt
   ```

4. سرور را اجرا نمایید:
   ```powershell
   python app.py
   ```
   > سرور روی آدرس `http://127.0.0.1:5000` آماده به کار خواهد بود.

---

### ۲. اجرای فرانت‌اند (Frontend)

برای مشاهده رابط کاربری می‌توانید از یکی از دو روش زیر استفاده کنید:

#### روش اول (ساده‌ترین راه):
به پوشه `frontend` بروید و روی فایل `index.html` دابل کلیک کنید تا در مرورگر پیش‌فرض شما باز شود.

#### روش دوم (با Live Server یا سرور محلی پایتون):
یک ترمینال جدید باز کرده و دستور زیر را اجرا کنید:
```powershell
cd frontend
python -m http.server 3000
```
سپس در مرورگر خود آدرس زیر را باز کنید:
[http://127.0.0.1:3000](http://127.0.0.1:3000)
